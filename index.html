احمد بخشیان؛ توسعه‌دهنده Laravel و Vue

توسعه‌دهنده بک‌اند با تمرکز بر PHP و Laravel و تجربه در Vue، طراحی سامانه و حل چالش‌های فنی.

درباره من

من احمد بخشیان هستم. از مواجهه با چالش‌های فنی لذت می‌برم و معتقدم نرم‌افزار خوب ترکیبی از منطق درست و تجربه کاربری مناسب است.

مهارت‌ها

  • Laravel و PHP
  • Vue.js و Tailwind CSS
  • MySQL و طراحی پایگاه داده
  • Docker و Linux
  • طراحی سامانه و ذخیره‌سازی موقت

سوابق کاری و ارتباط

تجربه همکاری در نقش‌های توسعه‌دهنده PHP و توسعه‌دهنده تمام‌پشته را دارم. برای آشنایی بیشتر با سوابق و شروع همکاری می‌توانید از بخش تماس همین صفحه استفاده کنید.
